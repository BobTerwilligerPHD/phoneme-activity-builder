# Phoneme Activity Builder

CSE3CWA Assessment 1 - Frontend Design and Usability

A builder tool for Speech Pathology teachers to create phoneme-based classroom activities. You build a Wordle-style guessing game or a Word Search using phoneme symbols instead of normal spelling, preview it in the browser, then download it as a standalone HTML file that runs anywhere.

This is Assessment 1 so it's frontend only, no database. Word lists are fixed for now, that's coming in Assessment 2.

Pages: Home, About, Wordle, Word Search, Settings (light/dark theme, saved in a cookie).

## Running it

```
npm install
npm run dev
```

Then go to localhost:3000

Built with Next.js, React and Tailwind.
